# OncoViva v2 — DrNB Surgical Oncology

Mobile-first progressive web app starter for personal exam preparation.

## Features
- PYQ-style practice mode (original practice questions, not claimed to be actual past-paper questions)
- Trial-focused question mode
- Image-based teaching schematics
- Timed 20-question mock examination
- Daily 20-question challenge
- Topic filters, bookmarks, incorrect-answer revision and local progress

## Publish free with GitHub Pages
1. Create a public repository named `oncoviva`.
2. Upload `index.html`, `manifest.json`, and `sw.js` to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. Wait for GitHub Pages to publish, then open the displayed URL.

## Important
This is a starter question bank with illustrative teaching schematics, not a comprehensive or independently audited question bank. “PYQ-style” means exam-style practice; these are not represented as actual previous-year questions. Check trial details and clinical facts against primary publications and current guidelines. For education only, not clinical decision-making. Progress is stored locally in the browser and does not sync across devices.
